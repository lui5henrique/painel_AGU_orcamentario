Clique para selecionar ou arraste os 3 arquivos .xlsx aqui
Selecione (ou arraste) os 3 arquivos de uma vez — cada aba é identificada automaticamente pelo nome, não importa a ordem:
• base_contratos(tratada).xlsx — aba Contratos
• empenhos_comprasnet(tratada).xlsx — aba empenhos
• ordens_bancarias(tratada).xlsx — aba OB_semanal_5
Um único workbook com as 3 abas também funciona. Se faltar algum, a base atual não é alterada.
